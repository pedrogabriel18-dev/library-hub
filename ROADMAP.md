# Roadmap de Desenvolvimento — LibraryHub

Este documento apresenta a visão de evolução e as futuras funcionalidades planejadas para o **LibraryHub**.

---

## 📌 Versão Atual (v2.0.0)

- [x] Arquitetura modular profissional baseada em recursos (`features/`).
- [x] Camada de serviços (`services/`) desacoplada do React.
- [x] Leitor imersivo de PDFs para livros e Trabalhos de Conclusão de Curso (TCCs).
- [x] Moderação de resenhas enviadas por estudantes.
- [x] Gestão administrativa completa de usuários, livros e categorias.
- [x] Sistema de notificações flutuantes Toast.
- [x] Acessibilidade WCAG AA com navegação por teclado e alto contraste.
- [x] Suíte de testes de integração automatizada com Vitest.

---

## 🚀 Próximas Etapas (Next Release — v2.1.0)

- [ ] **Internacionalização (i18n)**: Suporte aos idiomas Português, Inglês e Espanhol.
- [ ] **Módulo de Empréstimos Físicos**: Controle de retiradas, devoluções e renovações presenciais de obras físicas.
- [ ] **Exportação de Relatórios**: Geração de relatórios gerenciais em PDF e Excel para bibliotecários.
- [ ] **Dashboard com Gráficos Interativos**: Gráficos de leitura por turma utilizando Recharts.

---

## 🔮 Visão de Longo Prazo (Future & Long Term)

- [ ] **Aplicativo Mobile nativo**: App iOS e Android desenvolvido com React Native.
- [ ] **Integração com APIs Externas de Livros**: Busca automática de metadados via Google Books API e Open Library API.
- [ ] **Suporte a Arquivos EPUB**: Leitor integrado para o formato EPUB.
